# Krud · Sistema de gestión

Inventario, ventas, fiado y caja para tiendas, veterinarias y otros negocios, en Windows. Funciona sin internet.

## Instalar

1. Entra a **[Releases](https://github.com/ScaryKosmitos/Krud/releases/latest)** y descarga el archivo
   **Krud-X.Y-instalador.exe**.
2. Ábrelo y sigue los pasos. No pide permisos de administrador.
   Si Windows avisa **«Windows protegió su PC»**, toca **Más información → Ejecutar de todas formas**.
3. La primera vez que se abre Krud sale el asistente para configurar el negocio.

## Actualizar

No hace falta descargar nada: cuando sale una versión nueva, Krud la avisa en la barra lateral y se
actualiza solo con **«Actualizar ahora»**. Actualizar nunca borra los datos.

## Dónde quedan los datos

En `C:\Users\<usuario>\AppData\Local\Krud`: la base de datos, la configuración y los respaldos.
Ni actualizar ni desinstalar el programa los toca.
